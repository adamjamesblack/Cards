# HealthEquity brand hub

An interactive, self-contained home for the HealthEquity brand — built from the
*HealthEquity Brand Style Guide (March 2026)* via the in-repo design system
(`oe-experience/_ds/`).

**Open `index.html` in any browser.** No build step, no server required.
(Photography thumbnails load from `../oe-experience/assets/photography/`, so keep
the folder inside this repo or serve the repo root.)

## What's inside

- **Search everything** — press `⌘K` / `Ctrl K` (or `/`) to search colors, rules,
  type styles, tools and downloads. Selecting a color copies its HEX.
- **Color** — the full palette with one-click copy for HEX, RGB, CMYK (process
  conversion) and CSS variables; the six approved gradients with copyable CSS;
  a live WCAG contrast checker.
- **Logo studio** — preview the logo on brand surfaces with automatic
  purple/white guidance and a clear-space overlay; download SVGs, copy the SVG
  code, or export transparent PNGs at 512–4096 px (rendered in the browser).
- **Typography** — an editable specimen across the whole type scale (click any
  row to copy its CSS), a letter-spacing demo, and the serif "human moment".
- **Voice and tone** — principles, do/don't pairs, the tagline with a copy
  button, and a headline checker that converts copy to brand sentence case and
  flags all caps, Title Case, emoji and shouting.
- **Graphics** — a Wayfinder builder with approved fills and SVG export.
- **Photography, expression modes, and components** — imagery guidance, the
  three-mode reskin demo, and copy-paste CSS for pills, cards, badges and states.

## Notes

- Neue Haas Grotesk Text Pro is licensed and not bundled; the page substitutes
  Inter (per the design system's convention).
- CMYK values are computed process conversions — confirm official print values
  with the brand team before production.
